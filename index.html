关于

这里放的是我自己在用的东西，不是产品目录。安卓端统一用 Kotlin + Jetpack Compose 原生写，NAS 端多是飞牛 fnOS 的 FPK 或 Docker 镜像，服务端一般落在 Cloudflare（Worker / Pages / Tunnel）。能开源的一律公开源码，涉及个人数据的只留私有仓库。

站点本身是纯静态页面，托管在 Cloudflare Pages，域名 apps.wenjun.eu.org；推送 GitHub 即自动部署。
